## [2.0.0](https://github.com/jklaiber/ebpf-bridge/compare/v1.0.1...v2.0.0) (2026-11-26)


### ⚠ BREAKING CHANGES

* the service listens on /run/ebpf-bridge.sock with mode 0660 instead of the world-writable /tmp/ebpf_bridge.sock, so the CLI must run as root or as a member of the socket's group. CLI commands now exit with a non-zero code on failure.
